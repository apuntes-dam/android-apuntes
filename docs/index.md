# Android y apps móviles

Apuntes para entender el terreno de las **aplicaciones móviles** antes de programarlas: dispositivos, redes, sistemas operativos, tecnologías de desarrollo, **Android Studio**, emuladores y ciclo de vida de una app. Los ejemplos usan **Kotlin y Jetpack Compose**.

!!! info "Cómo está organizado"
    Una unidad de teoría con siete apartados y, debajo, sus ejercicios, que se desbloquean al marcar la unidad como leída.

| Apartado | Contenido |
|---|---|
| [U1 · Tecnologías para dispositivos móviles](u01/index.md) | Dispositivos, redes, sistemas, nativo vs multiplataforma, Android Studio, emuladores y ciclo de vida |
| [Ejercicios](u01/ejercicios.md) | 8 ejercicios prácticos |

!!! note "Android Studio es una herramienta, no un lenguaje"
    **Android Studio** es el entorno de desarrollo (IDE) oficial de Android. El lenguaje que se usa dentro es **Kotlin** (o Java). Por eso esta web enlaza con la de [Kotlin](https://apuntes-dam.github.io/kotlin-apuntes/) y, para apps multiplataforma, con la de [Dart y Flutter](https://apuntes-dam.github.io/dart-flutter-apuntes/).
