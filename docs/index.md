# Android y apps móviles

Apuntes para aprender a **programar aplicaciones Android**: desde las tecnologías móviles hasta construir interfaces completas con botones, imágenes, formularios, listas, navegación, temas y datos. Los ejemplos usan **Kotlin y Jetpack Compose**, y la última unidad repasa las **vistas XML clásicas**.

!!! info "Cómo está organizado"
    Cada unidad empieza por lo **básico** y termina con apartados «para ir más allá». Después vienen sus **ejercicios**, que se desbloquean al marcar la unidad como leída, de fáciles a retos ⭐. Algunos tienen solución modelo bloqueada.

!!! note "Android Studio es una herramienta, no un lenguaje"
    **Android Studio** es el entorno de desarrollo (IDE) oficial de Android. El lenguaje que se usa dentro es **Kotlin** (o Java). Por eso esta web enlaza con la de [Kotlin](https://apuntes-dam.github.io/kotlin-apuntes/) y, para apps multiplataforma, con la de [Dart y Flutter](https://apuntes-dam.github.io/dart-flutter-apuntes/).

!!! warning "Código sin ejecutar en este entorno"
    Los fragmentos de Android no se han ejecutado al escribir estas páginas (hacen falta el SDK y un emulador). Pruébalos en tu proyecto y, si algo no compila, revisa los `import` (**Alt+Enter** en Android Studio).
