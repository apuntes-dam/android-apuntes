# U12 · Usabilidad y accesibilidad (DIN, tema 6)

Decidir **con números** si una interfaz se puede usar: medir el contraste de cada texto, el área de toque de cada control, comprobar que la letra se puede poner al 200 % y demostrar que un lector de pantalla entiende cada pieza. Es el tema 6 de *Desarrollo de Interfaces* ([página del profesor](https://revilofe.github.io/section6/u06/teoria/DI-U6.1.-UsabilidadYAccesibilidad/)), con los estándares que hay que saber citar. Los **cálculos** (contraste, área de toque, SUS) están escritos en Kotlin puro y **ejecutados de verdad**. Al final tienes la página **Lo marcado en verde**, con lo que el profesor resalta explicado con otras palabras.
