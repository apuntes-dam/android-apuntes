# AA3 · Datos y repositorios

Casi toda app vive de datos que llegan de **internet** y se guardan en el **móvil**. La pregunta es cómo organizarlo para que la pantalla no sepa ni de dónde vienen, para que la app **funcione sin conexión** y para que los errores no la rompan. La respuesta es una capa intermedia: el **repositorio**.
